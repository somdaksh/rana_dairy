# Rana Dairy Farm --- Responsive Business Website

A responsive, single-page business website created for **Rana Dairy
Farm**, a local dairy farm based in Madhkarimpur, Khatauli,
Muzaffarnagar, Uttar Pradesh.

The website presents the farm, its milk products, daily operations,
location, and contact information in a clean, responsive interface
designed for both desktop and mobile users.

## Features

-   Responsive single-page website
-   Sticky navigation bar with smooth scrolling
-   Hero section with farm introduction and call-to-action buttons
-   Cow milk and buffalo milk product sections
-   Farm story / about section
-   Custom farm illustrations and icons using SVG
-   Farm gallery section
-   Google Maps location embed
-   Click-to-call phone links
-   WhatsApp contact links
-   Farm hours and address information
-   Responsive layouts for smaller screens
-   CSS animations and hover effects
-   Custom typography using Google Fonts

## Tech Stack

-   **HTML5** --- page structure and content
-   **CSS3** --- styling, responsive layouts, animations, transitions,
    and media queries
-   **SVG** --- custom illustrations, icons, and visual elements
-   **Google Fonts** --- Fraunces, Mukta, and Space Mono
-   **Google Maps Embed** --- displaying the farm location

## Sections

The website contains the following main sections:

1.  **Hero** --- Introduction to Rana Dairy Farm with call-to-action
    buttons.
2.  **Trust** --- Highlights the farm's freshness and purity claims.
3.  **About** --- Background and story of the farm.
4.  **Products** --- Information about cow milk and buffalo milk.
5.  **Gallery** --- Visual illustrations representing farm activities.
6.  **Location** --- Farm address and embedded Google Maps.
7.  **Contact** --- Phone and WhatsApp contact options.
8.  **Footer** --- Farm information and contact details.

## Responsive Design

The website uses CSS media queries to adapt the layout for smaller
screens. Navigation, grids, hero content, product cards, gallery
sections, and contact sections adjust for mobile and tablet screen
sizes.

## Getting Started

No build tools, package installation, or backend setup is required.

### Run Locally

1.  Clone the repository:

``` bash
git clone <your-repository-url>
```

2.  Open the project folder.
3.  Open `rana-dairy-farm.html` in any modern web browser.

Alternatively, you can use **VS Code with Live Server** for local
development.

## Deployment

The project is a static HTML/CSS website and can be deployed using
static hosting services such as GitHub Pages, Vercel, or Netlify.

## Project Purpose

The website was created to provide Rana Dairy Farm with an online
presence where visitors can:

-   Learn about the farm
-   Explore available milk varieties
-   View farm-related content
-   Find the farm location
-   Contact the farm directly
-   Access phone and WhatsApp communication options
